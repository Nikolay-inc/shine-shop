Создай в этом репозитории (shine-shop) веб-прототип мобильной игры Shine Shop: расслабляющая ASMR-реставрация старых вещей с прокачкой и автоматизацией (idle). Стек: TypeScript + Three.js + Vite + Vitest; интерфейс — HTML/CSS поверх канваса. Вертикальный экран 9:16, касания и мышь.

Ядро:
- В центре на подставке 3D-предмет (тёплый свет, мягкие тени, фон мастерской). Палец по предмету — чистка; палец по пустому месту — вращение предмета; щипок — приближение.
- Чистка: raycast в точку касания → UV → рисуем в маску (canvas-текстура 512–1024). Шейдер смешивает чистый материал предмета и процедурную грязь по маске. Грязь генерируется шумом поверх любой модели, 2 слоя: «пыль/грязь» (берёт любой инструмент) и «ржавчина/налёт» (только инструмент уровня 2+; слабым инструментом чистится очень медленно).
- Прогресс чистоты в % (по маске в низком разрешении). На 97% — автодочистка, искры, звон, короткий показ «до/после».
- ASMR-звук: шорох через WebAudio (фильтрованный шум, громкость и тон зависят от скорости пальца и инструмента), звон на финише, тихая фоновая мастерская. Выключатель звука.

Экономика и мета:
- Готовый предмет продаём → монеты. Цена зависит от предмета и редкости. 1 из 20 предметов — «золотая находка» ×5.
- Инструменты (радиус, скорость, какие слои берёт): губка → щётка → мойка высокого давления → лазер. Скины инструментов (2–3 варианта) за монеты.
- Помощники: верстак с автоматом, который сам чистит предметы и даёт монеты в секунду (видно, как он работает, в углу экрана). Улучшения скорости.
- Доход без игрока: до 2 часов, при возвращении — окно «Пока тебя не было: +N монет».
- Альбом «Коллекция»: карточки восстановленных предметов, редкости, счётчик.
- Всегда видна ближайшая цель (следующий инструмент, следующий предмет в альбоме). Поражений нет.

Модели:
- Для прототипа — 5–6 моделей CC0 с Poly Haven (polyhaven.com): старые вещи (лампа, фотоаппарат, чайник, инструмент, часы, кувшин). Скачай через их публичный API, если сеть доступна; если нет — подготовь загрузчик glTF из public/models и опиши в README, какие файлы положить. Текстуры 1k, сжатие (Draco/meshopt + KTX2 или webp), общий вес игры < 15 МБ.
- Пока моделей нет — процедурные предметы в коде (LatheGeometry: ваза, чашка, кувшин; монета, ключ), чтобы игра работала сразу.

Проверки:
- Логика экономики (цены, инструменты, офлайн-доход, редкость) — в src/core без Three.js, тесты на неё. npm run sim — симуляция первых 30 минут игры: когда игрок получает каждый инструмент и помощника. Цель: новая покупка каждые 1–3 минуты в первые 15 минут.
- SaveService (load/save, version, playerId-UUID) с сохранением времени выхода для офлайн-дохода.
- Лог событий (item_start, item_done, sell, buy_tool, buy_helper, offline_collect, session_end) и экран «Статистика» с кнопкой «Скопировать».
- Первый запуск — сразу первый предмет и рука-подсказка «проведи пальцем» без текста.
- Производительность: 60 fps на среднем телефоне, pixel ratio не больше 2, без ошибок в консоли. Вёрстка на 375x667 и 430x932.
- GitHub Actions: npm test, build с base=/<имя репозитория>/, деплой на Pages.
- CLAUDE.md: правила проекта, команды, устройство кода; коммиты на английском в формате feat:/fix:.
