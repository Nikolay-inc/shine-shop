# Shine Shop — правила проекта

Веб-прототип мобильной игры: расслабляющая ASMR-реставрация старых вещей + idle-автоматизация.
Исходное ТЗ — `docs/BRIEF.md`. Стек: TypeScript, Three.js, Vite, Vitest; UI — HTML/CSS поверх канваса.

## Команды

```bash
npm run dev       # дев-сервер (http://localhost:5173)
npm test          # Vitest: экономика, сохранения, лог, sim
npm run sim       # симуляция первых 30 минут: когда игрок получает инструменты и помощников
npm run verify    # то же с проверкой темпа (exit 1, если покупки реже чем раз в 3 мин в первые 15 мин)
npm run build     # tsc + vite build (в CI: --base=/<repo>/)
npm run models    # скачать и сжать модели Poly Haven в public/models (нужна сеть)
node scripts/shots.mjs [url] [outDir]   # headless-прогон в системном Chrome + скриншоты (дев-сервер должен работать)
```

## Устройство кода

- `src/core/` — чистая логика без Three.js и DOM (покрыта тестами):
  - `config.ts` — весь баланс: предметы, инструменты, скины, помощники, редкости, константы.
  - `economy.ts` — формулы: цена, редкость, мощность инструмента, доход помощников, офлайн-доход (кап 2 ч), выбор предмета.
  - `state.ts` — `GameState` и действия (start/complete/sell item, buyTool/Skin/Helper, tickHelpers, collectOffline, goals). Золотая находка — «мешок»: ровно 1 из 20.
  - `save.ts` — `SaveService`: version, playerId (UUID v4), lastSeen (время выхода), миграции/нормализация.
  - `events.ts` — `EventLog` (item_start, item_done, sell, buy_tool, buy_skin, buy_helper, offline_collect, session_start, session_end).
- `src/game/` — 3D и игровой цикл:
  - `stage.ts` — рендерер (pixel ratio ≤ 2), мастерская, подставка, тёплый свет с мягкими тенями, вращение/зум, raycast, снимок «до/после».
  - `procedural.ts` — процедурные предметы (Lathe: чашка, ваза, кувшин, чайник…; монета, ключ) — работают без моделей.
  - `items.ts` — `ItemFactory`: glTF из `public/models` по `manifest.json` (meshopt + webp) или процедурный фолбэк; шаблоны кэшируются.
  - `itemPrep.ts` — нормализация модели, атлас `maskUv` (непересекающийся UV для маски), растр поверхности 512² (позиции), отсечение скрытых поверхностей лучами, пространственный хэш для 3D-кисти, генерация грязи шумом (пыль + ржавчина ровно на заданной доле).
  - `dirtMaterial.ts` — патч `MeshStandardMaterial` (onBeforeCompile): смешивает чистый материал с пылью/ржавчиной по маске.
  - `cleaner.ts` — маска-canvas 512² (R = пыль снята, G = ржавчина снята), 3D-кисть, прогресс по сетке 128².
  - `input.ts` — жесты: палец по предмету = чистка, по пустому месту = вращение, щипок/колесо = зум.
  - `fx.ts` — 2D-эффекты поверх WebGL (пена, пыль, брызги, лазер, искры).
  - `game.ts` — оркестратор: цикл кадра, жизненный цикл предмета, автодочистка на 97 %, покупки, офлайн, сохранения, лог.
- `src/audio/sound.ts` — WebAudio без файлов: шорох (фильтрованный шум по скорости пальца и инструменту), звон, монетки, фон мастерской.
- `src/ui/` — HUD, цели, виджет помощника, листы (магазин, помощники, коллекция, статистика), модалки.
- `scripts/sim.ts` — симуляция темпа; `scripts/fetch-models.mjs` — модели; `scripts/shots.mjs` — e2e-скриншоты.

## Правила

- Логика экономики — только в `src/core` (без импорта three/DOM). Любое изменение баланса — прогнать `npm test` и `npm run sim`; цель: покупка каждые 1–3 мин в первые 15 мин.
- Новое поле в `GameState` → значение по умолчанию в `createState`; `normalize()` в `save.ts` подтянет его в старые сохранения. Ломающее изменение формата → поднять `SAVE_VERSION` и добавить миграцию.
- Новое событие → тип в `EventType` и счётчик на экране «Статистика».
- Производительность: pixel ratio ≤ 2, одна тень 1024, без аллокаций в горячем цикле, без ошибок в консоли. Проверять вёрстку на 375×667 и 430×932.
- Ассеты: только CC0, текстуры 1k, сжатие meshopt + webp, общий вес `dist` < 15 МБ (проверяется в CI).
- Коммиты на английском в формате Conventional Commits: `feat: ...`, `fix: ...`, `chore: ...`, `test: ...`, `docs: ...`.
- CI (`.github/workflows/deploy.yml`): `npm test` → `npm run verify` → build с `--base=/<repo>/` → проверка веса → деплой на GitHub Pages (только `main`).
